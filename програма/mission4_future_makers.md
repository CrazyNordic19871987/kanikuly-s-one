# МИССИЯ 4: FUTURE MAKERS — АКАДЕМИЯ ПРИКЛАДНОГО БУДУЩЕГО

## Обзор программы

**Название:** FUTURE MAKERS: Академия Прикладного Будущего  
**Подзаголовок:** STEM & DESIGN THINKING  
**Целевая аудитория:** 7–12 лет  
**Стартовая команда:** 20 человек  
**Длительность:** 5 дней (понедельник — пятница)  
**Режим дня:** 10:00 – 17:00  

### Легенда
Дети — стажёры «Института Прикладного Будущего». Каждый день они работают в новой лаборатории: Робототехника, Программирование, Экотехнологии, Дизайн или Медицина. В финале — объединяются в команды и запускают собственный стартап.

### Направления

1. **💻 IT** — лаборатория робототехники, программирование, IoT: умное устройство, хакатон
2. **🧬 Биотех** — экотехнологии, медицина, биоинженерные решения
3. **🎨 Art & Design** — лаборатория дизайна, концепт-арт, прототипирование
4. **🏅 Спорт** — лабораторная разминка, инженерная эстафета, программистская йога
5. **📊 Предпринимательство** — стартап-команды, интервью с пользователями, Demo Day

**Конкретный результат:** Работающий робот, объезжающий препятствия. Программа загружена.

**Применяемые навыки:**
- Решение проблем (конструирование)
- Креативность (дизайн робота)
- Программирование (логика движения)
- Командная работа

**XP:** +25 за работающего робота

## Необходимые материалы

### 💻 IT
- Наборы Arduino / micro:bit (1 на 2 человека)
- Датчики: расстояния, температуры, влажности
- USB-кабели
- Компьютеры/планшеты для Scratch/Python
- Колёса, моторы, корпуса для роботов

### 🧬 Биотех
- Пульсометры / смартфоны
- Материалы для моделей энергии (фольга, paper, моторы)
- Таблицы для записи данных
- Микроскоп (по возможности)

### 🎨 Art & Design
- Бумага A3, маркеры, карандаши
- картон, пластилин, клей, ножницы
- Компьютеры для графического редактора

### 🏅 Спорт
- Blazepod LED-панели (4-6 штук)
- Балансборды
- Конусы, фишки для эстафет
- Мячи футбольные (размер 3-4)
- Коврики для дзюдо

### 📊 Предпринимательство
- Бланки контрактов стартапа
- Калькуляторы
- Проектор для Demo Day

## Примечания для вожатых

1. **Безопасность:** Все технические работы проводятся под наблюдением. Ножницы, пайка — только с разрешения.

2. **Дифференциация:**
   - 7-8 лет: Scratch (блоковый), простые конструкции
   - 9-10 лет: Python (начальный), Arduino
   - 11-12 лет: Python (средний), IoT-проекты

3. **Геймификация:** XP начисляется в конце каждого блока. Таблица лидеров обновляется перед ужином.

4. **Demo Day:** Пригласите родителей на финальный день. Это мотивирует детей.

5. **Документирование:** Фото/видео каждого дня для отчёта родителям.
