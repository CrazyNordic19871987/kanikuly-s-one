# МИССИЯ 3: META-AGENCY — ДЕТЕКТИВЫ ВРЕМЕНИ

## Обзор программы

**Название:** META-AGENCY: Детективы Времени  
**Подзаголовок:** MEDIA & SOFT SKILLS  
**Целевая аудитория:** 7–12 лет  
**Стартовая команда:** 20 человек  
**Длительность:** 5 дней (понедельник — пятница)  
**Режим дня:** 10:00 – 17:00  

### Легенда
Временной континуум нарушен, и только дети-агенты «Meta-Agency» могут его восстановить. Каждый день — новое детективное дело: расшифровать код, опросить свидетелей, собрать доказательства и сделать вывод.

### Направления

1. **🎬 Медиа** — детективный ролик, подкаст агента, хромакей и ИИ-монтаж, финальный брифинг
2. **🏅 Спорт** — капоэйра, фехтование на мягких мечах, фрисби-алтимат, доджбол-турнир
3. **💻 IT** — расшифровка шифров, цифровое портфолио агента, ИИ-монтаж видео
4. **🤝 Дипломатия** — интервью со свидетелями, межагентские переговоры, защита расследования

## Примечания для вожатых

1. **Безопасность:** Фехтование проводится только с мягкими мечами и под наблюдением. Доджбол — мягкие мячи.

2. **Дифференциация:**
   - 7-8 лет: упрощённые шифры, больше помощи при съёмке
   - 9-10 лет: стандартный уровень
   - 11-12 лет: сложные шифры, роль продюсера

3. **Геймификация:** XP начисляется в конце каждого блока. Таблица лидеров обновляется перед ужином.

4. **Инклюзия:** Каждый ребёнок имеет роль в «расследовании». Роли распределяются по сильным сторонам.

5. **Документирование:** Все видео/подкасты сохраняются на USB для родителей.
