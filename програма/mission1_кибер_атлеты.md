## Обзор программы

**Название:** КИБЕР-АТЛЕТЫ: Хроники Будущего  
**Целевая аудитория:** 7–12 лет  
**Стартовая команда:** 20 человек  
**Длительность:** 5 дней (понедельник — пятница)  
**Режим дня:** 10:00 – 17:00  

### Направления

1. **🏅 Спорт** — нейрофитнес, балансборды, лазертаг, archery tag, мечевой бой
2. **💻 IT** — micro:bit, сборка датчиков, анализ данных, эко-полис
3. **🧬 Биотех** — биохакинг, анализ данных тела, зелёные технологии
4. **📊 Предпринимательство** — нейро-коины, питчинг, юнит-экономика
5. **📦 Продуктовый инкубатор** — создание датчика-гаджета на micro:bit (финальный проект)

## Примечания для вожатых

1. **Безопасность:** Все спортивные активности проводятся под наблюдением тренера. Дети делятся на группы по возрасту/уровню.

2. **Дифференциация:** Задания адаптируются под возраст:
   - 7-8 лет: упрощённые инструкции, больше помощи
   - 9-10 лет: стандартный уровень
   - 11-12 лет: дополнительные挑战и, роль наставника

3. **Геймификация:** XP начисляется в конце каждого блока. Таблица лидеров обновляется перед ужином.

4. **Продуктовый инкубатор:** Гаджет собирается поэтапно:
   - День 1: Знакомство с micro:bit
   - День 3: Сборка датчика
   - День 4: Настройка + питчинг
   - День 5: Финальная доработка + защита

5. **Инклюзия:** Каждый ребёнок участвует в командных заданиях. Роли распределяются так, чтобы каждый мог проявить сильные стороны.

6. **Документирование:** Фото/видео каждого дня для отчёта родителям.
