# Система классов и прокачки — Bio-Crafters

## 1. Архитектура прокачки

### 1.1 Уровневая система

| Уровень | Название | XP от | XP до | Бонус |
|---------|----------|-------|-------|-------|
| 1 | Новичок | 0 | 200 | — |
| 2 | Стажёр | 200 | 500 | +1 слот инвентаря |
| 3 | Ученик | 500 | 900 | Доступ к редким миссиям |
| 4 | Практикант | 900 | 1 400 | +5% к XP за командные миссии |
| 5 | Специалист | 1 400 | 2 000 | Новый аватар |
| 6 | Эксперт | 2 000 | 2 700 | Доступ к «Хакатону» |
| 7 | Мастер | 2 700 | 3 500 | Титул в профиле |
| 8 | Профи | 3 500 | 4 400 | +1 слот инвентаря |
| 9 | Гуру | 4 400 | 5 400 | Уникальный бадж |
| 10 | Легенда | 5 400 | ∞ | Золотая рамка профиля |

**Формула XP до следующего уровня:** `base + (level × 150)`, где base = 200.

### 1.2 Источники XP

| Действие | Базовый XP | Модификаторы |
|----------|-----------|--------------|
| Выполнение миссии | 50–150 | +20% за первое место в отряде |
| Командная миссия | 80–120 | +10% за каждого активного участника |
| Творческий проект | 100–200 | +30% за презентацию экспертам |
| Спортивное испытание | 40–80 | +15% за победу |
| Вечерний квест | 30–60 | +25% за решение без подсказок |
| Помощь товарищу | 20 | Макс 3 раза в день |
| Ежедневный вход | 10 | Стрик: +5 XP за каждый день подряд (макс +25) |

## 2. Система классов (10 смен = 10 ролей)

Каждая смена — это «класс» в RPG-терминологии. Участник получает XP в навыки, соответствующие смене. После прохождения всех смен формируется доминирующий класс.

### 2.3 Определение доминирующего класса

После каждой смены система пересчитывает доминирующий класс:

```
class_score[engineer]    = (tech + analytic × 0.5) / 1.5
class_score[media]       = (creative + comm × 0.5) / 1.5
class_score[nature]      = (nature + tech × 0.3) / 1.3
class_score[leader]      = (team + comm × 0.5) / 1.5
class_score[analyst]     = (analytic + tech × 0.3) / 1.3
```

Максимальный score = активный класс профиля. Можно переключать вручную, но система подсвечивает рекомендуемый.

## 5. Формулы для фронтенда

```javascript
// XP до следующего уровня
function xpToNextLevel(level) {
  return 200 + (level * 150);
}

// Прогресс в процентах
function xpProgress(currentXP, level) {
  const prev = xpToNextLevel(level - 1);
  const next = xpToNextLevel(level);
  return ((currentXP - prev) / (next - prev)) * 100;
}

// Начисление XP с модификаторами
function grantXP(base, modifiers) {
  let total = base;
  modifiers.forEach(m => total *= (1 + m));
  return Math.round(total);
}

// Расчёт доминирующего класса
function getDominantClass(skills) {
  const scores = {
    engineer: (skills.tech + skills.analytic * 0.5) / 1.5,
    media:    (skills.creative + skills.comm * 0.5) / 1.5,
    nature:   (skills.nature + skills.tech * 0.3) / 1.3,
    leader:   (skills.team + skills.comm * 0.5) / 1.5,
    analyst:  (skills.analytic + skills.tech * 0.3) / 1.3
  };
  return Object.entries(scores).sort((a,b) => b[1] - a[1])[0][0];
}
```

## 6. Рекомендации по внедрению

1. **Стартовый экран** — при первом входе участник проходит «тест на класс» (3 вопроса) и получает начальный аватар.
2. **QR-код на бейдже** — ведёт на профиль. Родители и вожатые сканируют для просмотра прогресса.
3. **Ежедневная сводка** — push-уведомление: «Ты получил +120 XP сегодня. Ещё 80 до уровня 8!»
4. **Табло в столовой** — ТВ с лидербордом отрядов в реальном времени.
5. **Финальный сертификат** — генерируется по итогам всех смен с радаром компетенций и списком баджей.
