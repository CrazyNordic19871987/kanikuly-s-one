## Список 13 баджей

### 1. 🔥 Первый огонь
- **Тир:** Обычный
- **Условие:** Завершить первую миссию любой смены
- **Иконка:** Пламя (SVG: `M12 24c0-6 4-10 4-14 0 0 4 4 4 10 0 4-2 8-6 8s-6-4-6-8z` с внутренним белым пламенем)
- **Описание:** «Ты сделал первый шаг. Огонь зажжён.»
- **Цвета:** Фон `#fff7ed`, рамка `#fdba74`, иконка `#ea580c`

### 2. 🧪 Лаборант
- **Тир:** Обычный
- **Условие:** Выполнить 3 лабораторных миссии (Bio-Engineering, Геном, Эко-разведка)
- **Иконка:** Колба с пузырьками (SVG: контур колбы + 3 круга внутри)
- **Описание:** «Руки в перчатках, голова в формулах.»
- **Цвета:** Фон `#f0fdf4`, рамка `#86efac`, иконка `#16a34a`

### 3. 🎥 Стример
- **Тир:** Обычный
- **Условие:** Снять и опубликовать 2 видеоотчёта
- **Иконка:** Камера на штативе с красной точкой записи
- **Описание:** «Ты в эфире. Мир смотрит.»
- **Цвета:** Фон `#fef2f2`, рамка `#fca5a5`, иконка `#dc2626`

### 4. 🏕️ Выживальщик
- **Тир:** Обычный
- **Условие:** Пройти полевой выход (ночёвка / поход / квест на природе)
- **Иконка:** Палатка с флагом + костёр
- **Описание:** «Природа — твой дом. Ночь — твой друг.»
- **Цвета:** Фон `#f0fdf4`, рамка `#86efac`, иконка `#15803d`

### 5. 🤝 Командный игрок
- **Тир:** Обычный
- **Условие:** Участвовать в 3 командных миссиях с положительным результатом
- **Иконка:** Три фигурки, взявшиеся за руки (силуэты)
- **Описание:** «Один за всех, все за дело.»
- **Цвета:** Фон `#eff6ff`, рамка `#93c5fd`, иконка `#2563eb`

### 6. 💡 Изобретатель
- **Тир:** Редкий
- **Условие:** Создать рабочий прототип (робот, механизм, устройство)
- **Иконка:** Лампочка с шестерёнкой внутри
- **Описание:** «Идея + руки = реальность.»
- **Цвета:** Фон `rgba(37,99,235,0.08)`, рамка `rgba(37,99,235,0.2)`, иконка `#2563eb`

### 7. 🌿 Эколог
- **Тир:** Редкий
- **Условие:** Провести 5 полевых исследований + защитить проект по экологии
- **Иконка:** Лист с лупой (жилки видны)
- **Описание:** «Ты видишь то, что другие не замечают.»
- **Цвета:** Фон `rgba(22,163,74,0.08)`, рамка `rgba(22,163,74,0.2)`, иконка `#16a34a`

### 8. 🎯 Снайпер
- **Тир:** Редкий
- **Условие:** Выполнить 5 миссий с оценкой «отлично» подряд
- **Иконка:** Мишень со стрелой в центре + кольца точности
- **Описание:** «Промахов не бывает.»
- **Цвета:** Фон `rgba(124,58,237,0.08)`, рамка `rgba(124,58,237,0.2)`, иконка `#7c3aed`

### 9. 🏆 Мастер
- **Тир:** Редкий
- **Условие:** Достичь 5-го уровня + пройти 2 смены полностью
- **Иконка:** Кубок с лавровой ветвью
- **Описание:** «Ученик перерос учителя.»
- **Цвета:** Фон `rgba(202,138,4,0.08)`, рамка `rgba(202,138,4,0.2)`, иконка `#ca8a04`

### 10. 🌟 Легенда
- **Тир:** Легендарный
- **Условие:** Достичь 8-го уровня + получить 8 баджей
- **Иконка:** Звезда с лучами + кольцо славы
- **Описание:** «Твоё имя войдёт в историю лагеря.»
- **Цвета:** Фон `linear-gradient(135deg, #fef3c7, #fde68a)`, рамка `#ca8a04`, иконка `#92400e`
- **Эффект:** CSS-анимация `pulse` — мягкое свечение золотым

### 11. ⚡ Хакатонщик
- **Тир:** Легендарный
- **Условие:** Пройти 3 смены + участвовать в финальном хакатоне
- **Иконка:** Молния + кодовые скобки `{ }`
- **Описание:** «Скорость. Код. Победа.»
- **Цвета:** Фон `linear-gradient(135deg, #fef3c7, #fde68a)`, рамка `#ca8a04`, иконка `#92400e`

### 12. 🧭 Путешественник
- **Тир:** Легендарный
- **Условие:** Пройти все 10 смен
- **Иконка:** Компас с картой в фоне
- **Описание:** «Ты видел все миры Bio-Crafters.»
- **Цвета:** Фон `linear-gradient(135deg, #fef3c7, #fde68a)`, рамка `#ca8a04`, иконка `#92400e`

### 13. 🏛️ Архитектор
- **Тир:** Легендарный
- **Условие:** Создать 10 завершённых проектов (по одному за смену)
- **Иконка:** Колонна + треугольник (как в архитектуре) + молоток
- **Описание:** «Ты строишь не просто проекты — ты строишь будущее.»
- **Цвета:** Фон `linear-gradient(135deg, #fef3c7, #fde68a)`, рамка `#ca8a04`, иконка `#92400e`

```javascript
const badgeConditions = {
  'first-fire':    (p) => p.missionsCompleted >= 1,
  'lab-assistant': (p) => p.labMissions >= 3,
  'streamer':      (p) => p.videosPublished >= 2,
  'survivor':      (p) => p.fieldTrips >= 1,
  'team-player':   (p) => p.teamMissions >= 3,
  'inventor':      (p) => p.prototypesBuilt >= 1,
  'ecologist':     (p) => p.fieldResearch >= 5 && p.ecoProject,
  'sniper':        (p) => p.streakExcellent >= 5,
  'master':        (p) => p.level >= 5 && p.shiftsCompleted >= 2,
  'legend':        (p) => p.level >= 8 && p.badges.length >= 8,
  'hackathoner':   (p) => p.shiftsCompleted >= 3 && p.hackathon,
  'traveler':      (p) => p.shiftsCompleted >= 10,
  'architect':     (p) => p.projectsCompleted >= 10
};
```
